# AI Local Guide App

AI-powered travel and local discovery assistant.

## Features
- Current location detection
- Search any city
- AI-powered recommendations
- Interactive map
- Nearby cafés, restaurants, tourist spots
- React + TypeScript + Vite
- Leaflet + OpenStreetMap
- Supabase-ready architecture

## Setup

```bash
npm install
npm run dev
```

## APIs To Integrate
- Nominatim API
- Overpass API
- Open-Meteo
- OpenRouter API (Gemini via OpenRouter)
- Geoapify Places API (malls, cafés, attractions, and more)
- Supabase
